# NetWatch

🇷🇺 Русский · [🇬🇧 English](README.en.md)

Диагностика домашней сети для macOS. Отвечает на вопрос «где ломается»: Wi-Fi/роутер, провайдер, DNS или VPN.

Все замеры (кроме HTTPS) привязаны к физическому интерфейсу (`en0`), поэтому VPN их не искажает. HTTPS идёт
по маршруту по умолчанию и показывает то, что реально видят приложения.

Лицензия: [MIT](LICENSE).

## Возможности

- **Где ломается.** Wi-Fi/роутер, провайдер, DNS и VPN определяются раздельно. Короткие сбои не считаются проблемой, а повторяющиеся складываются в инциденты.
- **Виджет** среднего и большого размера: цветной статус, график с переключателем «час · сутки · неделя», клик открывает приложение.
- **Уведомления** о проблеме, которая длится дольше минуты, с вероятной причиной.
- **Причины скачков задержки.** Трафик самого Mac, AWDL (AirDrop и Handoff), энергосбережение, загрузка процессора, другие устройства в сети.
- **Каждая сеть отдельно.** Дом, корпус, раздача с телефона считаются порознь. Сети, где закрыт ping, распознаются автоматически.
- **Роутер Tenda.** Трафик через роутер, число устройств, время соединения с провайдером. Данные читаются без пароля, в роутер ничего не записывается.
- **Экономно.** Замер раз в 30 с, чаще только пока есть проблема, на батарее реже.

## Требования

- macOS 15 или новее.
- Xcode и [xcodegen](https://github.com/yonaskolb/XcodeGen) для сборки приложения и виджета.
- Сертификат Apple Development (достаточно бесплатного Apple ID).

## Структура

- `Sources/NetWatchCore` — ядро: замеры, диагностика, инциденты, сети, хранилище, адаптивный планировщик, отчёт.
- `Sources/NetWatchUI` — экраны виджета, общие для виджета и окна приложения.
- `Sources/netwatchd` — консольный агент.
- `App/` и `Widget/` — приложение-хозяин (окно настроек, уведомления) и расширение виджета.
- `Tests/` — тесты логики диагностики, сетей, уведомлений, роутера и хранилища.
- `scripts/` — установка агента и приложения, пересборка анимаций.

## Использование

```bash
swift build -c release
.build/release/netwatchd run          # фоновый сбор (30 с, при проблемах — каждые 3 с, на батарее реже)
.build/release/netwatchd once         # один замер
.build/release/netwatchd report --hours 24 [--network ИМЯ]   # отчёт, по каждой сети отдельно
.build/release/netwatchd networks     # сети, в которых бывал Mac
.build/release/netwatchd name current "Корпус А"   # назвать текущую сеть
.build/release/netwatchd router       # что сейчас сообщает роутер (Tenda)
```

Лог: `~/Library/Application Support/NetWatch/samples-YYYY-MM-DD.jsonl` (хранится 30 дней).

## Виджет

Средний и большой виджет для панели виджетов macOS: цветной статус, четыре ключевых показателя, график задержек
с полосой состояний, а в большом ещё Wi-Fi (канал, DFS, сигнал), данные роутера и последние инциденты.
Графики за сутки и неделю строятся из 15-минутных сводок (`rollups.json`), которые ведёт агент.

```bash
scripts/install.sh        # агент-логгер (launchd), собирает данные
scripts/install-app.sh    # приложение + виджет → ~/Applications/NetWatch.app (нужен xcodegen)
```

Для подписи нужен сертификат Apple Development (бесплатного Apple ID достаточно): команда определяется из него автоматически,
либо задайте её вручную: `NETWATCH_TEAM=ABCDE12345 scripts/install-app.sh`. Идентификаторы бандла (`com.egor.*`) замените на свои в `project.yml` и `scripts/install.sh`.

Добавить: правый клик по рабочему столу → «Изменить виджеты» → NetWatch.

- `project.yml` — описание проекта Xcode (`NetWatch.xcodeproj` генерируется и в git не хранится).
- `swift run netwatch-preview build/previews` рисует виджет в PNG без WidgetKit.
- Иконка приложения рисуется кодом (`Sources/netwatch-icon`): `swift run netwatch-icon App/Assets.xcassets/AppIcon.appiconset`.
- Виджет работает в песочнице и читает лог агента через узкое разрешение «только чтение»
  (`com.apple.security.temporary-exception.files.home-relative-path.read-only`). Для App Store такое не подходит, для личной установки — да.
- Само расширение обновляется системой по бюджету, поэтому приложение-хозяин следит за логом и просит обновление
  при смене состояния и раз в минуту. Приложение работает в фоне: у него нет значка в Dock, окно открывается кликом по виджету.

## Что считается проблемой

| Вердикт | Условие |
|---|---|
| Нет сети | нет интерфейса или роутера |
| Wi-Fi/роутер | не проходит ничего: ни роутер, ни интернет |
| Провайдер | роутер отвечает, но оба внешних адреса недоступны напрямую |
| DNS | DNS-сервер не отвечает |
| VPN | прямой путь работает, а HTTPS через VPN — нет |
| Деградация | потеряно >20% эхо-пакетов, молчит ICMP роутера при живом интернете, роутер >30 мс, интернет >150 мс, DNS >300 мс, HTTPS >3 с |

Вердикт пересчитывается из сырых замеров при чтении лога, поэтому правки правил действуют и на старые данные.

В отчёте отдельно отмечаются смены Wi-Fi канала и совпадения инцидентов с DFS-каналами (52–64, 100–144).

## Приватность

Данные хранятся только на вашем Mac. Для проверки связи агент обращается к вашему роутеру и вашим DNS-серверам, а также
к 1.1.1.1, 8.8.8.8 и странице apple.com, больше никуда. Роутер он только читает, пароль не нужен.
